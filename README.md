# What is Bandit Bros?
Since 2023, we have been constantly creating games, from Roblox events like The Showdown to
upcoming Steam releases like Text Bob. Our team of passionate programmers, artists, 3D modelers, designers, and
voice actors work together to create fun, memorable experiences for players around the world.
